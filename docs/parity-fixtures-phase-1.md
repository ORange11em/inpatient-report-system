## 1. บริบทที่ต้องคงเหมือนกัน

- หอสมมติ A รหัสเดิม `10`, หอสมมติ B รหัสเดิม `11`; ทั้งสองเปิดใช้ อยู่กลุ่มรายงาน 1 จึงไม่เข้าเงื่อนไขตัดเตียง `12/13/16` ของยอดรวมครองเตียง
- เวรเดิม `1=ดึก`, `2=เช้า`, `3=บ่าย`; ระบบใหม่จับคู่ด้วย `legacy_shift_id` แล้วใช้รหัสหลักจริงของฐานทดสอบ ห้ามสมมติว่ารหัสหลักเท่ากับ 1/2/3
- C คือ `i_status=1` / `confirmed`; U คือ `i_status=0` / `unconfirmed`; ช่องที่ไม่มีรายการคือขาดเวร ไม่สร้างแถวศูนย์หรือสถานะใหม่แทน
- บัญชีสมมติ R-A บันทึกและยืนยันหอ A, R-B บันทึกและยืนยันหอ B, V-A อ่านหอ A อย่างเดียว, M ดูแลระบบ; “หัวหน้าหอ” ใช้สิทธิ์จริงที่มอบหมาย ไม่สร้างบทบาทใหม่จากตำแหน่งงาน
- ช่วง 31 ต.ค.–2 พ.ย. 2569 เก็บวันที่เป็น ISO ตามด้านล่าง; รายงานปีงบประมาณ 2570 ใช้ ต.ค. 2569–ก.ย. 2570; วันที่/เดือนบนหน้าจอต้องผ่าน `frontend/lib/thai-date.mjs`
- เริ่มจากสำเนาชุดตั้งต้นทุกครั้งก่อนทดสอบแก้ไข/ยืนยัน/ส่งกลับ เพื่อให้ตัวเลขรายงานและจำนวนค้างยังเทียบกันได้

## 5. ตัวอย่างเล็กเฉพาะข้อขัดแย้ง Productivity (F17)

เริ่มจากสำเนา A1101N/M/E อีกชุด ให้ทุกแถวมีประเภท5=3 ประเภท4=3 ประเภท3/2/1=0 เจ้าหน้าที่คง1/2/1/1/1 (6คนต่อเวร); ตัวเลขเคลื่อนไหวไม่เข้าคำนวณ Productivity ห้ามเอาชุดนี้ทับ P1 v1 ต้นฉบับ เมื่อตรวจข้อยกเว้นให้เปลี่ยนเฉพาะรหัสหอเป็น12,13,28ทีละรอบ ไม่ต้องสร้างหอจริงเพิ่มในชุดหลัก

## 6. วิธีใช้และระดับหลักฐาน

1. ตรึง P1 v1 และแยกสำเนาสำหรับแต่ละกรณี ตรวจจำนวน13/C8/U5ก่อนเริ่ม; ข้อมูลตัวชี้วัดไม่ใช้สถานะเวรกรองแทนโดยอัตโนมัติ
2. เฟสพัฒนาให้สร้าง fixture จาก CSVและค่าเริ่มต้นที่ระบุในฐานทดสอบใหม่ ส่วน PHP ใช้สำเนาฐานทดสอบที่ได้รับอนุญาตหรือคำนวณจากนิพจน์ ห้ามเขียนฐาน/ซอร์สต้นทาง
3. รัน workflow F01/F06/F14 ก่อนแล้วคืนชุดตั้งต้น; รายงาน F02–F13/F17ใช้ฐานเดิมไม่ปะปนผลแก้ไข ตรวจแถวรายเวร/รวมวัน/รวมเวรเดือน/รวมเดือนแยกกัน
4. ค่าทศนิยมเปรียบเทียบกับค่าปัดสองตำแหน่งจากบริการก่อนตรวจรูปแบบUI; หน้าจอที่แสดงหนึ่งตำแหน่งไม่ใช่เหตุให้แก้ค่าที่ส่งออก ทดสอบศูนย์/ไม่มีตัวหาร/ไม่มีรายการแยกกัน
5. เก็บหลักฐานชื่อกรณี บทบาท วัน/เวร หอ ตัวกรองสถานะ ตัวเลขจอ/พิมพ์/ไฟล์ และข้อDที่เลือกแล้ว การปิดช่องว่างต้องมีหลักฐานใหม่ ไม่ยกผลเฟส7เดิมมาใช้แทน

รอบเฟส1นี้ตรวจตัวเลขจากตารางด้วย Python และเรียกฟังก์ชันรายงานใหม่ในหน่วยความจำ ไม่เปิดบริการ ไม่เขียนฐาน ไม่รันPHP ไม่ถือเป็นผลย้ายข้อมูลหรือผลตรวจหน้าจอจริง รายละเอียดผลรอบนี้อยู่ท้าย [รายการตรวจรับ](../INPATIENT_PARITY_TH.md)
