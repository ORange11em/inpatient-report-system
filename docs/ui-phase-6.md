# เฟส 6 — รายงาน อัตราการครองเตียง และพิมพ์/ส่งออก

19 พฤศจิกายน 2569 · ทำเฉพาะ `/reports`, `/occupancy` และองค์ประกอบร่วมที่เกี่ยวข้อง ไม่เริ่ม QA รวมเฟส 7

## ขอบเขตที่เจ้าของงานยืนยัน

- อนุญาตโหลดรายงานเริ่มต้นอัตโนมัติด้วย GET เดิม และเพิ่ม GET รายวันเดิมเพื่อแสดงยอด/ความครบถ้วน โดยคงพารามิเตอร์ สูตร และสิทธิ์
- เลือก **“คง Excel XML เดิม”** จึงใช้ `.xml` จริง ไม่เปลี่ยนนามสกุลเป็น XLSX และไม่เพิ่ม dependency
- ให้ชื่อ **“โรงพยาบาลอากาศอำนวย”** / Akat Amnuai Hospital สำหรับหัวพิมพ์ ใช้ชื่อไทยที่ผู้ใช้ให้ ไม่เพิ่มตราหรือหน่วยงานสมมติ
- ยังไม่ตอบเกณฑ์สี Q07 จึงใช้ร้อยละแบบเป็นกลาง และแยกข้อมูลครบ/ไม่ครบ/ไม่มีค่า พร้อมข้อความสูตรรายเดือนชั่วคราว ไม่ถือว่าคำตอบนี้อนุมัติสูตรหรือตัวหาร

ภาพ [05-report-daily.png](screenshots/05-report-daily.png) และ [06-bed-occupancy.png](screenshots/06-bed-occupancy.png) ทำสำเนาจากภาพเดิม `Screenshot 2026-11-19 144427.png` / `144441.png` เพราะไม่พบชื่อ alias ที่ระบุตอนเริ่ม เก็บต้นฉบับครบและตรวจ SHA-256 เท่ากัน

## หน้ารายงาน

คงรายงาน 15 ประเภทสำหรับผู้ดูแลและ 13 ประเภทสำหรับบัญชีอื่น โดย `census-day`/`census-month` ยังเฉพาะผู้ดูแลตามเดิม จำนวนเกิน 5 จึงใช้ Select ประเภทรายงาน ชื่อหน้า/breadcrumb เปลี่ยนตามรายงาน และคงสอง route กับค่าเริ่มต้น daily/occupancy

FilterBar ใช้ ThaiDatePicker/ThaiMonthPicker/FiscalYearSelect และชื่อ “สถานะข้อมูล” มือถือเปิด BottomSheet มีตัวกรองที่ใช้เป็น chip และจำเงื่อนไขใน query ของ path เดิม เปิดหน้าแล้วโหลดค่าเริ่มต้นที่อนุญาตอัตโนมัติ การเปลี่ยนตัวกรองทั่วไปยังต้องกด “แสดงรายงาน” ช่วงเดือนคงกฎวันแรกของเดือน/เดือนสิ้นสุดไม่ก่อนเริ่ม และปี พ.ศ. มีช่วงเดิม 2543–3543

หัวรายงานแสดงช่วง/ขอบเขตหอ/สถานะข้อมูลและ **เวลาเรียกดูข้อมูล** จริง ไม่อ้างว่าเป็นเวลาแก้ไขล่าสุดจากบริการ ปุ่มพิมพ์/ส่งออกมีไอคอน เหตุผล disabled และ loading ส่งออก ข้อมูลผิดพลาด/ไม่มีข้อมูล/มีแต่ชื่อหอกับ null ไม่เปิดส่งออก ค่าศูนย์จริงยังนับเป็นข้อมูล

ตารางรายงานทั่วไปคงทุกแถว/คอลัมน์และตัวเลขจากบริการ แสดง StatusBadge ตามข้อความสถานะที่มีจริง คงแถวรวมที่บริการส่งและนำแถวรวมท้ายตารางไปเป็น footer โดยไม่รวมซ้ำ บนมือถือเป็นการ์ด กดเปิดข้อมูลครบทุกช่องหรือสลับตารางได้

ยอดรวมรายวันแสดงในแถบสรุป PT: คงเหลือเวรล่าสุดต่อหอ รับและจำหน่ายรวมวันที่เลือก เตียงว่าง และร้อยละจากฐานเตียงของเวรล่าสุด พร้อม “บันทึกครบเวรที่เลือก x/y หอ” และรายชื่อที่ยังขาด ไม่รวมยอดตั้งต้นหลายเวร และไม่แต่งยอดเมื่อฐานเตียง/ลำดับเวรไม่ทราบ ตารางตัวเลขจาก backend ไม่ถูกแก้ด้วยการคำนวณแสดงผลนี้

## อัตราการครองเตียง

- หัวเดือนใช้ util กลางเป็น ต.ค. 69 … ก.ย. 70 ข้อมูลครบใช้ `bed_rate`/`average` เดิม ทศนิยมหนึ่งตำแหน่ง ค่าศูนย์แสดง 0.0% ส่วน null เป็น —
- ข้อมูลไม่ครบแสดงจำนวนบันทึก/จำนวนต้องมี พร้อม progress และคำอธิบายที่แตะ/กดคีย์บอร์ดได้ หน่วยเวรอธิบายใน legend ไม่ซ้ำทุกเซลล์ ไม่เผยร้อยละที่ยังไม่ complete
- เฉลี่ยปี/ปีก่อนและแถวรวมใช้ `fiscal_year`, `previous_fiscal_year`, `total` ที่บริการส่ง ไม่เฉลี่ยหอเอง ส่วนต่าง ▲/▼/= เป็นจุดร้อยละและแสดงเมื่อ complete/มีค่าทั้งสองปีเท่านั้น
- Sticky header/คอลัมน์หอ เลื่อนในกรอบ ชื่อหอเก็บข้อความเต็มใน title และตัดช่องว่างเกิน มือถือเป็นการ์ดเฉลี่ย/ปีก่อน/ส่วนต่าง/ความครบถ้วน เปิดดู 12 เดือนได้ และสลับตาราง
- สูตรและตัวหารชั่วคราวยังเป็นของ backend ไม่แก้ `occupancy.py`, กลุ่มหอที่ยกเว้น, วิธีนับเวร หรือค่าเฉลี่ย

## Excel XML และปี พ.ศ.

ตรวจดาวน์โหลดจริงครบ 15 ชนิด ตัวอย่าง `รายงานประจำวัน_19-11-2569.xml`, `อัตราการครองเตียง_ปีงบ2570.xml`, รายงานช่วงเดือนใช้ปี พ.ศ. ทั้งสองฝั่ง

XML ยังคง schema Excel Spreadsheet เดิม ช่องตัวเลขเป็น `ss:Type="Number"` และค่าตรงข้อมูลตอบกลับทุกเซลล์ รวม 0 และทศนิยมเดิม ไม่ใส่คอมมา/ปัดค่าตัวเลขในไฟล์ null ยังคงช่องว่าง แปลงเฉพาะหัวเดือน/คอลัมน์วันที่ที่ทราบความหมายเป็น พ.ศ. ไม่สแกนเปลี่ยนชื่อหอหรือข้อความอื่นแบบกว้าง และ escape ข้อความตามเดิม

ดูรายชื่อไฟล์และจำนวนเซลล์ที่เทียบใน [browser-checks.json](screenshots/phase-6/browser-checks.json) และไฟล์ตัวอย่างสมมติใต้ `screenshots/phase-6/exports/` ส่วนต่างครองเตียงเป็นข้อมูลแสดงผลบนจอ/พิมพ์ การส่งออกคงคอลัมน์ชุดเดิมจากบริการ

## พิมพ์ A4 แนวนอน

ใช้หน้า HTML เดียวกับรายงานและ `@page { size: A4 landscape; margin: 12mm 10mm; }` ซ่อน navigation/ตัวกรอง/ปุ่ม/skip link หัวพิมพ์มีโรงพยาบาล ชื่อรายงาน ช่วง เงื่อนไข ผู้พิมพ์จากบัญชีปัจจุบัน เวลาพิมพ์และเวลาเรียกดู พ.ศ. ใช้ beforeprint ปรับเวลาก่อนเปิดหน้าต่างพิมพ์ตาม [แนวทาง React](https://react.dev/reference/react-dom/flushSync)

ตารางกว้างแบ่งชุดคอลัมน์พร้อมทวนหอ/วัน/เวรในทุกชุด เพื่อคงทุกช่องและใช้ตัวอักษร 9pt หัวกระดาษ/หัวคอลัมน์อยู่ใน thead เพื่อซ้ำทุกหน้า แถวไม่ถูกตัดกลาง ส่วนตารางครองเตียงแสดงครบทั้ง 12 เดือน เฉลี่ยปี/ปีก่อนและส่วนต่างในหนึ่งแนวกว้าง ใช้ตัวเลข/สัญลักษณ์/เส้นตารางที่อ่านได้เมื่อไม่พิมพ์พื้นหลังสี

ไฟล์พิมพ์จริงจาก Edge headless ด้วยข้อมูลสมมติ:

- [รายงานประจำวัน A4 แนวนอน](../output/pdf/daily-a4-landscape.pdf) — กรณีทดสอบ 34 หอ × 2 แถว, 45 คอลัมน์ แบ่ง 5 ชุด รวม 31 หน้า จำนวนหน้าขึ้นกับข้อมูล ไม่ใช่จำนวนตายตัวในหน้าใช้งาน
- [อัตราการครองเตียง A4 แนวนอน](../output/pdf/occupancy-a4-landscape.pdf) — 34 หอและแถวรวม รวม 3 หน้า

ตรวจขนาดทุกหน้าประมาณ 841.92 × 594.96 pt (A4 แนวนอน), หัวโรงพยาบาล/ตารางซ้ำทุกหน้า, ไม่มี ISO/เมนู, แถวสมมติครบ 340 แถวในชุดรายวันและ 34 หอในครองเตียง, ไม่มีข้อความออกนอกกระดาษ จากนั้นเรนเดอร์ทุกหน้าด้วย Poppler และตรวจภาพ: [ผลตรวจ](screenshots/phase-6/print-checks.json), [ภาพรวมรายวันทุกหน้า](screenshots/phase-6/print/daily-all-pages.jpg), [ภาพรวมครองเตียงทุกหน้า](screenshots/phase-6/print/occupancy-all-pages.jpg)

ผลนี้เป็นการตรวจ browser print/PDF ยังไม่ใช่การตรวจเครื่องพิมพ์จริงหรือการเปิดไฟล์ใน Microsoft Excel จริง
